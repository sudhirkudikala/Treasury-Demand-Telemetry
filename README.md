# 📊 Treasury Demand Telemetry

An automated, data-engineering pipeline that captures and visualizes institutional market demand and structural duration risk from U.S. Treasury coupon auctions. 

Instead of hiding behind static curve movements, this engine focuses on high-signal liquidity indicators—tracking auction clearing mechanics instantly as fresh data is released by the **U.S. Bureau of the Fiscal Service**.
